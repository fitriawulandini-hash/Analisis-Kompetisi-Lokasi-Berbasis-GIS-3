Analisis Kompetisi & Lokasi Berbasis GIS

Repositori ini berisi studi kasus materi Pertemuan 3 mengenai pemanfaatan Sistem Informasi Geografis (GIS) untuk analisis spasial dan persetujuan lokasi strategis di era industri[cite: 1].

## 📌 Fitur Aplikasi
- Simulasi penilaian kelayakan lokasi berdasarkan jarak ke pusat kota dan tingkat kepadatan kompetitor.
- Sistem skoring otomatis untuk menentukan apakah suatu titik koordinat strategis dijadikan lokasi bisnis.
- Tampilan web interaktif berbasis GitHub Pages.

## 📁 Struktur File
- `index.html`: Website interaktif simulasi analisis GIS.
- `README.md`: Dokumentasi dan penjelasan proyek.
